# EchoVerse v1.6.3 — Auto Update Fix

## Windows auto updater

v1.6.3 release MUST contain all three Windows updater assets:

- `EchoVerse Setup 1.6.3.exe`
- `EchoVerse Setup 1.6.3.exe.blockmap`
- `latest.yml`

`latest.yml` is mandatory. `electron-updater` reads it to discover the current Windows version,
installer filename and checksum.

The app checks GitHub Releases automatically about 4.5 seconds after startup.

Update flow:

1. Installed EchoVerse starts.
2. GitHub Releases is checked.
3. New version is detected.
4. Download starts automatically.
5. Progress is visible on every EchoVerse page.
6. When download completes, EchoVerse shows a notification and a global banner.
7. After 5 seconds it restarts and installs automatically.
8. The banner also has `Şimdi yeniden başlat`.

Updater failures are no longer hidden. They remain visible in the UI and are also written to:

`%APPDATA%\echoverse-desktop\echoverse-updater.log`

(The exact userData folder can vary with Electron app naming.)

## Important

Windows builds are currently unsigned. This is separate from the updater logic and can still
trigger SmartScreen / Defender reputation warnings. Code signing is the production fix.

macOS automatic updating is not considered reliable until Apple signing/notarization is configured.
The release still provides Intel and Apple Silicon DMG/ZIP downloads.

## Release procedure

First push main, then create the tag only after the Windows test workflow succeeds.

    git add .
    git commit -m "EchoVerse v1.6.3 auto update fix"
    git push origin main

Run `Test Windows Build`.

If green:

    git tag v1.6.3
    git push origin v1.6.3

Do not manually create a GitHub Release first. The `Release EchoVerse` workflow creates the release.
