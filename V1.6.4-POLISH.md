# EchoVerse v1.6.4 — Polish & Stability

v1.6.4 is intentionally a stability/polish release.

## Auto Update
- Designed as the first real v1.6.3 -> v1.6.4 automatic-update validation.
- Release workflow hard-fails if Windows `latest.yml`, installer or blockmap is missing.
- `latest.yml` is checked to ensure it actually advertises 1.6.4.
- Electron Builder never publishes directly; one GitHub Release job owns publishing.
- Existing v1.6.3 global updater progress/error/restart UI is preserved.

## DM
- Fixes stale React/socket state that could make an open DM fail to receive live messages.
- Open DM now reliably receives new messages without reopening the conversation.
- Duplicate message IDs are ignored.
- Unread counter clears when the conversation is opened.
- Friend rows show unread badges.
- New messages auto-scroll the active conversation.
- Typing indicator automatically stops after inactivity.
- Switching back to server view clears typing/composer state.

## Private Calls
- Server voice and private voice remain mutually exclusive.
- Double outgoing calls are blocked.
- Incoming call brings the caller's DM into focus.
- Call duration timer is shown.
- Ringback/ringtone remain distinct.
- Call end has a short end tone.
- Ending a private call does not automatically return to server voice.

## Connection polish
- Temporary disconnect/reconnect state is visible instead of silently looking frozen.

## Desktop + Web
- DM/socket/call polish is applied to both clients.
- Auto updater remains desktop-only.

## Test order
1. Keep EchoVerse v1.6.3 installed on Windows.
2. Push v1.6.4 main.
3. Run `Test Windows Build`.
4. Only if green, create/push tag `v1.6.4`.
5. Wait until the GitHub Release contains:
   - EchoVerse Setup 1.6.4.exe
   - EchoVerse Setup 1.6.4.exe.blockmap
   - latest.yml
6. Open the already-installed v1.6.3 and verify automatic discovery/download/restart.
