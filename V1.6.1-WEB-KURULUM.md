# EchoVerse v1.6.1 — Web

Bu patch v1.6'nın mevcut Windows/macOS sürümünü korur ve ayrıca tarayıcıdan çalışan
`web/` istemcisini ekler.

## Web adresi

GitHub Pages etkinleştirildikten ve `Deploy EchoVerse Web` workflow'u başarılı
olduktan sonra varsayılan adres:

https://berkkayhan34-sys.github.io/echoverse/

## GitHub Pages'i bir kere aç

Repo → Settings → Pages → Build and deployment → Source → GitHub Actions

Sonrasında `main` branch'e web değişiklikleri pushlandıkça site otomatik deploy edilir.

## Web'de çalışanlar

- Hesap oluşturma / giriş
- PostgreSQL'deki aynı hesaplar
- Sunucular ve text chat
- Arkadaş sistemi
- DM / private call altyapısı
- Mikrofon / kamera
- WebRTC ses ve görüntü
- Ekran paylaşımı: Chrome/Edge/Safari'nin kendi ekran seçicisi
- Tarayıcı bildirimleri (kullanıcı izin verirse)
- Input seçimi; output seçimi tarayıcı/setSinkId desteğine bağlı

## Web'e özel farklar

- Kurulum ve updater yok: sayfa açıldığında/yenilendiğinde en güncel web build gelir.
- Tray/menu bar davranışı sadece masaüstü uygulamasında vardır.
- Spotify Together browser OAuth henüz yapılandırılmadığı için web'de devre dışıdır.
