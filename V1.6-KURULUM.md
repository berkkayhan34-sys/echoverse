# EchoVerse v1.6.0

GitHub'daki v1.5.0 release tabanı üzerine hazırlanmıştır.

Dahil edilenler:
- v1.5.1 QoL: görünür updater durumu/yüzde altyapısı, manuel update kontrolü, mikrofon testi, output test sesi, unread DM state, tray DM/arama bildirimlerinin korunması, Socket.IO reconnect.
- v1.6 DM: presence (online/idle/DND/invisible), typing eventleri, reaction altyapısı, reply metadata, DM okunma state'i.
- v1.5 arkadaş/DM/private call/input-output/tray özellikleri korunur.

Not: sınırsız resim/dosya upload production için object storage gerektirdiğinden bu pakette binary dosyaları DB/socket içine sınırsız basan riskli bir çözüm eklenmemiştir.
