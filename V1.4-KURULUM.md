# EchoVerse v1.4

## Yeni özellikler

- Kayıt Ol / Giriş Yap ekranı.
- E-posta + kullanıcı adı + şifre.
- Şifreler bcrypt ile hashlenir.
- 30 günlük JWT oturumu ve uygulama açılışında otomatik giriş.
- Profil fotoğrafı yükleme/değiştirme.
- Profil fotoğrafı 256x256 JPEG'e küçültülür.
- Avatarlar voice listesi, online listesi ve mesajlarda görünür.
- Windows ekran paylaşımının macOS alıcıda görünmesi için:
  - remote video yalnızca video track ile render edilir;
  - remote video muted tutulur (audio ayrı oynatılır);
  - replaceTrack sonrasında WebRTC renegotiation yapılır;
  - offer çakışmalarında rollback desteği eklenir.

## ÖNEMLİ — Hesapların kalıcı olması

v1.4 veritabanı yoksa hesap sistemini RAM fallback ile çalıştırır.
Render restart/deploy olursa RAM hesapları silinir.

Gerçek kullanım için Render'da PostgreSQL oluşturup server servisine
DATABASE_URL environment variable olarak bağla.

JWT_SECRET de Render Environment bölümünde uzun ve rastgele bir değer olmalı.
Yeni render.yaml JWT_SECRET'i otomatik üretmeye hazırdır.

## Render kontrol

Deploy sonrası:

https://echoverse-c3d5.onrender.com

şuna benzer dönmeli:

{
  "name": "EchoVerse Server",
  "version": "1.4.0",
  "ok": true,
  "database": "postgres"
}

Eğer database "memory" yazıyorsa uygulama çalışır ama hesaplar kalıcı değildir.
