# EchoVerse v1.5

Yeni özellikler:
- Mikrofon / input cihazı değiştirme.
- Hoparlör / output cihazı değiştirme.
- Seçimler localStorage'da hatırlanır.
- Arkadaş kullanıcı adıyla arama.
- Arkadaşlık isteği gönderme / kabul / reddet / sil.
- PostgreSQL'de kalıcı arkadaşlıklar.
- Direct Message ve DM geçmişi.
- Arkadaşını özel sesli arama.
- Karşı tarafta çalma/ringing ekranı ve sistem bildirimi.
- Accept / Reject / End call.
- Windows ve macOS close-to-tray:
  - X'e basınca pencere gizlenir.
  - Ses/bağlantı tray/menu bar arkasında çalışmaya devam eder.
  - Tray ikonuna tıklayınca açılır/gizlenir.
  - Tray menüsü > "Tamamen Kapat" gerçek çıkıştır.
- macOS'ta pencere gizlenince Dock ikonu da gizlenir, tray/menu bar ikonu kalır.

Önemli:
- PostgreSQL zaten v1.4'te bağlandıysa yeni tablolar deploy sırasında otomatik oluşur.
- Server adresinde database=postgres görmelisin.
- Audio output değiştirme Chromium setSinkId desteğini kullanır.
- macOS'ta bazı özel Bluetooth/AirPlay route'larında işletim sistemi routing davranışı sınırlayabilir.
- Private call WebRTC mesh ve mevcut signaling kullanır.
- Daha sonra TURN/SFU eklemek uzak ağlarda güvenilirliği artırır.
