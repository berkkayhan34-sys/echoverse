# EchoVerse

EchoVerse is a real-time communication application for talking, messaging,
voice calls, video, screen sharing, and listening together with friends.

It provides two clients:

- a browser application for immediate access;
- a desktop application with native media capture, secure session storage,
  tray integration, and automatic updates.

## Features

- account registration and sign-in;
- servers, presence, chat, direct messages, friends, and private calls;
- microphone, camera, voice-lobby, and screen-sharing controls;
- English and Turkish interfaces, with English fallback for other locales.
