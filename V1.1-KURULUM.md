# EchoVerse v1.1 Update

## Eklenenler
- Gerçek çalışan "Sunucu oluştur"
- Sunucu koduyla katılma
- Sunucu değiştirme
- Disconnect düğmesi
- Ekran paylaşımında WebRTC video sender düzeltmesi
- Kamera / ekran arasında geçiş
- GitHub Releases tabanlı otomatik update
- Uygulama açılışında update kontrolü

## Server güncellemesi
GitHub reposundaki `server/src/index.ts` dosyasını bu paketteki ile değiştir.
Render auto-deploy açıksa birkaç dakika içinde v1.1 deploy olur.

## Desktop güncellemesi
`desktop` ve `.github` klasörlerini repodaki karşılıklarıyla güncelle.

## İlk v1.1 release
Terminal:

```powershell
git add .
git commit -m "EchoVerse v1.1"
git push

git tag v1.1.0
git push origin v1.1.0
```

Tag push edilince `.github/workflows/release.yml` çalışır ve GitHub Releases'a
Windows ve macOS paketlerini yükler.

Windows'taki eski EchoVerse v1.0 bu updater kodunu içermediği için v1.1'e otomatik
geçemez. v1.1'i kullanıcıların bir kez manuel kurması gerekir.

v1.1'den SONRA örneğin v1.2:
1. `desktop/package.json` version -> `1.2.0`
2. değişiklikleri push et
3. `git tag v1.2.0`
4. `git push origin v1.2.0`

v1.1+ Windows uygulaması açıldığında GitHub Release'i kontrol eder, yeni sürümü
indirir ve yeniden başlatıp kurar.

## macOS notu
macOS'ta güvenilir, tam otomatik update için Apple Developer code signing ve
notarization gereklidir. İmzasız build'lerde uygulama açılabilir, ancak update
kurulumu Gatekeeper tarafından engellenebilir. Production için sertifika eklenmeli.

## Server kalıcılığı notu
Şimdilik oluşturulan sunucular backend RAM'inde tutulur. Render restart/deploy
olursa sonradan oluşturulan sunucular silinir. Kalıcı sunucular/roller/mesajlar için
bir sonraki adım PostgreSQL veritabanıdır.
