# EchoVerse v1.6.2

Hem Windows/macOS masaüstü uygulaması hem de web istemcisi güncellendi.

## DM
- Arkadaş DM'i artık sağda/altta küçük panel olarak açılmaz.
- Arkadaşa tıklayınca ana içerik tamamen Discord benzeri özel mesaj sayfasına dönüşür.
- Tam sayfa mesaj geçmişi ve composer.
- Yazıyor göstergesi.
- Arkadaş durumu header'da görünür.

## Private call
- DM header'da Ara butonu.
- Arayan tarafta ringback/çalıyor tonu.
- Aranan tarafta ayrı ringtone.
- Accept / Reject.
- Arama kabul edildiğinde private voice session.
- Kullanıcı server voice kanalındaysa private call başlamadan önce server voice'tan çıkar.
- Server voice ve private call aynı anda mikrofon sesi gönderemez.
- Private call kapanınca kullanıcı eski server voice'a otomatik dönmez.

## Desktop + Web
Aynı App davranışı hem `desktop/src/App.tsx` hem `web/src/App.tsx` için uygulanmıştır.
