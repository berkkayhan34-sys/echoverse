# EchoVerse v1.3

Bu sürüm:
- macOS ekran paylaşımı için Electron desktop source picker kullanır.
- Mac'te Screen Recording izni yoksa Sistem Ayarlarını açtırır.
- Paylaşılan/kamera videosuna tıklayınca EchoVerse penceresini doldurur; tekrar tıklayınca veya ESC ile çıkar.
- Konuşan kullanıcı yeşil parlar.
- Ses slider + local mute artık Voice Channel listesinin altında da görünür; dar MacBook pencerelerinde sağ panel gizlense bile kontroller kaybolmaz.
- Uygulama sürümü kullanıcı panelinde görünür.

## macOS ekran paylaşımı

İlk kullanımda macOS izin istemez veya paylaşım açılmazsa:

System Settings
→ Privacy & Security
→ Screen & System Audio Recording
→ EchoVerse = ON

Sonra EchoVerse'i TAMAMEN kapat ve yeniden aç.

Bu macOS'un güvenlik kuralıdır; izin verildikten sonra uygulama source picker üzerinden ekran/pencere seçtirir.
