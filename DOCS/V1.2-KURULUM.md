# EchoVerse v1.2

## Eklenenler

- Electron ekran paylaşımı için gerçek desktop-capture handler.
- Ekran paylaşımı WebRTC video sender üzerinden karşı tarafa gider.
- Her kullanıcı için ayrı ses seviyesi: %0 - %200.
- Kullanıcıyı sadece kendi bilgisayarında mute etme.
- Spotify Together:
  - Her kullanıcı kendi Spotify hesabını bağlar.
  - Party liderinin çaldığı şarkı / konum / play-pause durumu odaya yayınlanır.
  - Diğer kullanıcıların kendi Spotify uygulamaları senkronize edilir.
- Otomatik updater v1.1'deki GitHub Releases sistemiyle devam eder.

## Spotify kurulumu — BİR KERE

Spotify Developer Dashboard'da bir uygulama oluştur.

Redirect URI olarak şunu ekle:

http://127.0.0.1:43821/callback

Sonra uygulamanın Client ID değerini:

desktop/config.json

içine koy:

{
  "serverUrl": "https://echoverse-c3d5.onrender.com",
  "spotifyClientId": "CLIENT_ID_BURAYA"
}

Spotify Client Secret uygulamaya konmaz. PKCE kullanılır.

Spotify Together için kullanıcıların Spotify Premium hesapları ve açık/erişilebilir
bir Spotify Connect cihazları olması gerekir. En kolay kullanım:
Spotify masaüstü/telefon uygulamasında önce herhangi bir şarkı aç → EchoVerse'te
Spotify Bağla → Birlikte Dinle.

## Server

server/src/index.ts artık v1.2'dir.
Render root directory = server olmalı. GitHub push sonrası Render auto-deploy eder.

Kontrol:
https://echoverse-c3d5.onrender.com

şuna benzer dönmeli:

{"name":"EchoVerse Server","version":"1.2.0","ok":true,...}

## Notlar

- macOS otomatik kurulum Apple Developer signing/notarization olmadan Gatekeeper'a
  takılabilir.
- Oluşturulan sunucular hâlâ RAM'dedir; Render restart olursa özel sunucular silinir.
  Kalıcılık için sonraki adım PostgreSQL.
- Büyük ses odalarında mesh yerine SFU/TURN gerekir.
