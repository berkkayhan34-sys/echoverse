# EchoVerse v1.6.6 — Windows + macOS updater fix

The v1.6.5 macOS updater problem was caused by treating two independently generated
`latest-mac.yml` files as release assets. Intel and Apple Silicon builds can overwrite
each other's metadata.

v1.6.6 changes:
- Intel and ARM jobs build but never publish directly.
- Each Mac job uploads uniquely named binaries and blockmaps only.
- The publish job downloads both architectures.
- One `latest-mac.yml` is generated from the final Intel + ARM ZIP files.
- SHA-512 and file sizes are calculated from the actual release files.
- The single metadata file is uploaded only once.
- Windows latest.yml remains generated by electron-builder and is verified before release.
- Windows workflow has no stale 1.6.5 checks.
- DM black-screen hotfix and startup updater UI polish remain included.

Release only after the Windows test passes.
