# EchoVerse v1.6.8 — Voice & Social

## Voice lobby
- Join sound when another person enters the voice lobby you are currently in.
- Leave sound when another person leaves that same voice lobby.
- No self join/leave sound.
- Short cooldown prevents sound spam when several users connect at once.
- Lobby sounds can be disabled from Ses Ayarları.
- Effect volume can be adjusted from 0–100.

## Release / updater pipeline
- Windows test and release workflows no longer hard-code the app version.
- Version is read from `desktop/package.json`.
- Release tags are validated against package version.
- Windows installer/update metadata checks are generated from the package version.
- macOS Intel and Apple Silicon artifact checks are generated from the package version.
- This removes the recurring `Version mismatch` and `Installer filename mismatch` maintenance problem.

## Existing v1.6.7 work retained
- DM drag & drop attachment support.
- Error Boundary / black-screen recovery.
- Per-user voice volume and local mute.
- Deafen and push-to-talk.
- Input/output device selection and mic test.
- Presence, DM social features and updater UI polish.

Camera/screen-share expansion remains outside this point release.
