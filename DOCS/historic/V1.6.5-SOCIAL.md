# EchoVerse v1.6.5 — Social / DM Polish

Desktop + Web:

- DM file/image sending now works.
- Attachment limit: 4 MB per DM file.
- Images render inline; other files show a download card.
- Attachments are persisted in PostgreSQL as bounded data URLs.
  This is intentionally a small-group solution. Larger uploads should move to object storage.
- Message edit/delete.
- Reply UI + reply metadata.
- Persistent emoji reactions.
- DM local search.
- Today/date dividers.
- Pending/active typing polish.
- Block user action.
- Presence selector: online / idle / DND / invisible.
- Deafen in private calls.
- Push-to-talk mode: hold V.
- Private-call timeout after 35 seconds.
- Missed-call notification.
- Call duration/ring/end-tone polish from 1.6.4 preserved.
- Reconnect + unread badges preserved.

Database migration runs automatically on Render startup using ADD COLUMN IF NOT EXISTS.

Updater:
- Windows artifactName stays `EchoVerse-Setup-${version}.exe`.
- latest.yml + blockmap are verified in both test and release workflows.
- v1.6.4 -> v1.6.5 auto update should work without manual installation.

Important:
The application remains unsigned on Windows/macOS. Signing/notarization is a separate production task.
