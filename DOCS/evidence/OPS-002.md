## Scope

- Defined executable HTTP, Socket.IO, call, reconnect, and SQLite resource
  budgets in [`reliability.md`](../reliability.md).
- Bounded renderer reconnect attempts and delay growth, with localized offline
  recovery and media cleanup after retry exhaustion.
- Rejected duplicate pending/active call starts server-side and capped pending
  calls at 1,024 entries.
- Made SQLite close idempotent and retained explicit PostgreSQL pool shutdown.
- Documented restart, cleanup, degraded database/network, retry, and
  idempotency behavior.

## Invariants

- No reconnect path retries forever or retries invalid credentials indefinitely.
- A duplicate call request cannot create a second call for the same pair while
  the existing call is pending or active.
- Pending call timers are cleared on answer, end, timeout, and socket
  disconnect.
- Socket disconnect and renderer teardown release transient call, peer, media,
  timer, and rate-limit resources.
- Malformed/oversized input is rejected before feature side effects, and
  operational logs remain payload-free.
