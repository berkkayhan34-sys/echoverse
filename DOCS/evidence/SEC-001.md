`GuildPermission` is a server-side deny-by-default evaluator with owner,
admin, moderator, and member inheritance. Equal/higher role changes are
rejected and channel/message operations use the evaluator. Unit tests cover
default denial and role hierarchy.

Permission overrides are persisted per guild/category/channel scope and the
most-specific explicit deny wins over inherited role defaults. Contracts and
negative tests cover unauthorized access, equal/higher role protection, and
invalid scopes; the shared package exports the role administration panel.
