## Scope

- Non-owner private guilds expose a visible, keyboard- and touch-accessible
  leave menu; the public main guild and owners remain protected by the
  existing server authorization.
- Guild voice peer setup is serialized per socket pair, uses a deterministic
  initiator to avoid offer glare, queues ICE candidates that arrive before the
  remote description, and acquires the microphone during the explicit join
  action.
- The DM composer keeps the message field flexible and the send action compact
  across desktop and narrow layouts.

recoverable on the work branch; no persisted data or production state was
modified.
