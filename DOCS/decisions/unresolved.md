# Unresolved decisions

No architecture decision currently blocks the documentation foundation.

Operational ownership, incident escalation, evidence retention, and release
approvers still need named people/processes before the first public release.
That is an execution detail tracked by the governance activation decision, not
an unresolved repository architecture choice.

Each resolution needs an ADR with alternatives, security impact, migration
steps, rollback, and evidence requirements.
