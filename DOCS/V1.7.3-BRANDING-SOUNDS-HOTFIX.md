# EchoVerse v1.7.3 — Branding & Sounds Production Hotfix

Fixes the production-only asset failures seen in v1.7.2.

- Renderer branding and sound URLs are now relative so they work under Electron `file://`.
- Login placeholder `E` is replaced by the supplied EchoVerse application icon.
- Supplied EchoVerse wordmark is used on the authentication screen.
- Windows tray/taskbar/splash assets are copied to `resources/branding` and loaded from `process.resourcesPath`.
- Splash loads the supplied splash artwork directly from disk.
- Voice join/leave now use the supplied WAV effects instead of generated oscillator tones.
- Incoming DM, mic toggle and incoming call use the supplied sound pack.
- Windows CI now checks that branding/sound assets exist both before and after the Vite production build.
