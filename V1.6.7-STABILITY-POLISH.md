# EchoVerse v1.6.7 — Stability + Chat Polish

- DM black-screen protection with a React Error Boundary.
- DM drag & drop attachment support and clearer attachment-ready state.
- Updater v2 UI is intentionally quieter and more consistent with the EchoVerse dark theme.
- Downloaded updates no longer force a restart after five seconds; the user chooses when to restart/install.
- Windows release/update metadata moved to v1.6.7.
- macOS Intel artifacts use the real `x64.zip` filenames produced by electron-builder.
- macOS Apple Silicon artifacts use the real `arm64.zip` filenames produced by electron-builder.
- Existing 1.6.6 DM/social, reaction, reply, edit/delete, presence, PTT and private-call work is retained.

Important macOS note:
Electron-builder requires macOS code signing for production auto-update. This package keeps
the Intel/ARM release pipeline correct, but a Developer ID signing identity must be configured
in CI before macOS auto-update can be considered production-ready.
